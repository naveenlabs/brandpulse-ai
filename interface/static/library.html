Reading

Opening this machine’s saved runs

Each one is read in full so its own trace can be drawn.

The library

Browsing the saved runs needs JavaScript, and this browser is not running it. The reports themselves are plain JSON on this machine and the API is still reachable: GET /reports lists them and GET /reports/<filename> returns one whole.

What a saved run contains

Every segment of one video with each of the four channels’ readings attached, every audience comment as classified, the two scores, and the caveats above. Author identifiers are never stored.
