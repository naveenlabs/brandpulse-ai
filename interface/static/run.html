Analyse a video

Starting a run needs JavaScript, and this browser is not running it. The API is still reachable: POST /analyse/start with a video_url, a brand_name and a product_name, then poll GET /analyse/status/<job_id>.

What a run costs

Four to nine minutes for one video, and considerably longer for a sweep of five. Ollama must be running on localhost:11434 with llama3.1:8b pulled. One run at a time.

What reaches a network

Two things, and nothing else: the video download and the comment fetch. Every model runs on this machine, and the controller is reached at localhost.
